# Data Directory

This directory stores representative student record samples for DAA Assignment 1.

Per the assignment specifications:
> `data/ (small samples; large ones are generated by script)`

## Contained Files:
- `students_sample_1000.csv`: Deterministic sample of 1,000 student records generated with seed `2347`. Contains registration number `192472347` (Somashekar Naidu).
- `students_sample_10000.csv`: Deterministic sample of 10,000 student records generated with seed `2347`. Contains registration number `192472347` (Somashekar Naidu).

## Large Datasets ($N = 100,000$ and $N = 1,000,000+$):
To adhere to Git best practices and prevent repository bloat, large datasets are generated dynamically on-demand in memory by:
```bash
python src/dataset_generator.py
```
or generated and loaded during benchmarking with:
```bash
python src/benchmark.py
```

## Record Schema:
| Column | Type | Example | Description |
| :--- | :--- | :--- | :--- |
| `reg_no` | Integer (9 digits) | `192472347` | Unique University Registration Number (Primary Key) |
| `name` | String | `Somashekar Naidu` | Student Full Name |

| `cgpa` | Float | `9.45` | Cumulative Grade Point Average |
| `semester` | Integer (1-8) | `5` | Current Academic Semester |
